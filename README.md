# Bell State Explorer

A beginner-friendly quantum computing project built with Qiskit.

This project demonstrates how Bell States are created, measured, affected by quantum noise, and compared using Fidelity calculations.

---

## Features

- Generate the four Bell States
- Visualize quantum circuits
- Execute circuits using Qiskit Simulator
- Display measurement counts
- Plot histograms
- Compare Ideal vs Noisy results
- Simulate depolarizing noise
- Calculate quantum state Fidelity

---

## Technologies

- Python
- Qiskit
- Qiskit Aer
- Qiskit Primitives
- Matplotlib

---

## Bell States

The project supports the four Bell States:

- Φ+
- Φ−
- Ψ+
- Ψ−
